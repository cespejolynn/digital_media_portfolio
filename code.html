Code as Art

I customized this drawing system by expanding the canvas size to 800 x 600 pixels and adding a soft purple background. I sort of made a lot of things purple, including a majority of the tools. I had fun experimenting with the tool options and adjusting them to be borderline impractical. I also messed around with the key options so the tool keys are no longer 1-7. I want to keep finding what keys respond to what tool an element of surprise and something you have to experiment with, but there are instructions on my github page. Users can made simple scribbles or doodles, and basically only in cool colors. Try using keys in the phrase "not chair bls" for tool selection!
